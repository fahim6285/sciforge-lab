# Mandatory scientific integrity and reproducibility checks

Reject or repair deliverables when:
- Figure points do not correspond to documented data, log records or actual equation outputs.
- Accuracy, latency, training duration, hardware, energy, class counts or comparison results were invented or projected as measured.
- Axis labels, units, time bases, plot interpolation, color legends or error bars obscure the true source values.
- Aggregate numbers conflict with source calculations; calculations include inappropriate denominators or mix unmatched populations.
- Code refers to missing assets/variables, overwrites original inputs or cannot be started from documented instructions.
- Cross-validation, baseline figures, subsets or test data were mixed in a way that produces misleading performance.
- Any personally identifying, restricted, confidential or user project-specific information is embedded into packaged reusable skills or examples.
- Figure filenames are linked before they exist; outputs are described as executed before a tool actually ran.

If a check cannot be completed because required inputs or runtimes are absent: make the remaining work useful, label exactly what was not verified, and provide the necessary next input. Never hide a scientifically consequential limitation.
