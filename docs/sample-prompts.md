# Sample prompts for SciForge Lab

Copy any prompt, attach your own source files and adjust the details.

1. Audit this dataset's fields, types, missingness and duplicates, then write a validation report.
2. Convert my MATLAB procedure to Python and show which tests actually passed.
3. Read the measured values and build high-resolution line and scatter figures, with the scripts.
4. Two tables and their figures disagree. Find the discrepancy from the actual data.
5. Create a Colab-friendly single-cell analysis workflow with deterministic output files.
6. Write an analysis brief and source manifest for this experiment.

Tip: attach the official source (posting, syllabus, methodology or CV) and say the exact output format you want. The agent works best when it can cite what you provided.
